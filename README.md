## 🛠️ Technology Stack & Performance Optimizations

* **Framework**: [Next.js 14 App Router](https://nextjs.org/) (Static Site Generation & Server-Side Rendering)
* **Language**: [TypeScript](https://www.typescriptlang.org/)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom Metallic Gold design tokens
* **Animations**: [GSAP](https://greensock.com/gsap/) with `ScrollTrigger` & [Framer Motion](https://www.framer.com/motion/)
* **Smooth Scrolling**: [Lenis](https://lenis.darkroom.engineering/)
* **Typography**: `Oswald` & `Outfit` (Google Fonts) + Google Material Symbols
* **SEO & Meta**: Complete OpenGraph, Twitter Cards, theme color, and `/golden-goat.png` favicons

```bash

# 3. Start development server

# 4. Build production bundle
npm run build
```
